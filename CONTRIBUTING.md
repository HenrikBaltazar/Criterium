# 🤝 Guia de Contribuição — Criterium

Agradecemos o seu interesse em contribuir com o **Criterium**!

O Criterium é uma plataforma baseada nos ideais de **transparência pública, auditoria factual e soberania em IA client-side**.

---

## 📜 Política de Licenciamento & Reconhecimento

O Criterium adota a **Criterium Community License v1.0 (CCL-1.0)**:
- **Código Aberto para Auditoria & Estudo**: Qualquer cidadão ou desenvolvedor pode inspecionar e auditar o código.
- **Contribuições em Troca de Créditos**: Não somos caridade e não permitimos a exploração comercial do projeto por terceiros sem licença comercial. Em contrapartida, **100% dos colaboradores da comunidade têm seu nome perpetuado com destaque oficial**.

---

## 🎖️ Como Funciona o Reconhecimento de Créditos

Ao ter um Pull Request aprovado e mesclado no repositório oficial:
1. Seu nome e link de perfil serão adicionados ao arquivo [`CONTRIBUTORS.md`](./CONTRIBUTORS.md).
2. Seu perfil será listado na seção **"Créditos da Comunidade"** dentro da própria aplicação web Criterium.

---

## 🚀 Passos para Contribuir

1. **Faça um Fork do Repositório**.
2. **Crie uma Branch para sua Feature ou Fix**:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. **Execute os Testes Automatizados**:
   ```bash
   cd tests && npm test
   ```
4. **Abra um Pull Request** detalhando as alterações e citando quais problemas foram corrigidos.
